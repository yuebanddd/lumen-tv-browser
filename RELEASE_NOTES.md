# Lumen TV Browser 0.1.0

Initial Android TV MVP based on TV Bro 2.1.6.

- New Lumen application identity, icon, TV banner, and home-page styling
- Independent package ID: `com.deeplumen.lumentvbrowser`
- Remote-first navigation, tabs, bookmarks, history, downloads, voice search, and ad blocking
- WebView-first release for smaller APK size and system-managed engine updates
- Simplified and Traditional Chinese branding
- Independent CI, release workflow, privacy policy, and upstream attribution

The built-in updater remains disabled until the first signed Lumen release channel is available.
